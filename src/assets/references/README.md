# Reference logos

Logos for `ReferencesWall` (ticket E): organisations Voxford performed for, from the KB's
`posao/klijenti/reference.md`, confirmed rows only (Josip: the logos may be used). Each file is the
organisation's own, downloaded on 2026-11-10 from the URL below; nothing is redrawn. The wall shows them
monochrome with CSS (`mono` in `src/content/references/<slug>.json`): `silhouette` turns the logo into
one light colour, `grayscale` keeps the inner contrast of logos that are a filled box.

Edits: `borotalco.png` cropped to the wordmark (no "Marchio storico" seal), `unisport.png` cropped to
Unisport Hrvatska (no Zaklada UniSport Srce), `efzg.svg` got a `viewBox`, PNG metadata stripped.
